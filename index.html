CÀI ĐẶT TRÊN MÁY TÍNH

Làm theo các bước dưới đây để sử dụng URLChecker trên Chrome hoặc Edge.

01

Tải URLChecker

Tải mã nguồn tiện ích URLChecker về máy tính.

⬇ TẢI TỪ GITHUB
02

Giải nén file

Nếu tải file ZIP, hãy giải nén file vào một thư mục trên máy tính.

03

Mở Chrome Extensions

Trên Chrome, truy cập:

chrome://extensions

Với Edge, truy cập:

edge://extensions
04

Bật Developer Mode

Bật chế độ Developer mode ở góc trên bên phải.

05

Load unpacked

Chọn Load unpacked và mở thư mục:

CyberGuard/Extension
06

Hoàn tất

URLChecker đã được cài đặt. Bạn có thể ghim tiện ích lên thanh công cụ và bắt đầu kiểm tra website.

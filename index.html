// INSTALLATION

CÀI ĐẶT URLCHECKER

01

Tải file URLChecker

Tải file ZIP của URLChecker từ GitHub.

↓ TẢI FILE
02

Giải nén file ZIP

Sau khi tải về, nhấp chuột phải vào file URLChecker.zip.

Chuột phải → Extract All...

Chọn nơi muốn lưu và nhấn Extract.

03

Mở thư mục Extension

Sau khi giải nén, mở:

URLChecker → Extension

Hãy chắc chắn thư mục này chứa:

manifest.json
background.js
check.html
check.js
warning.html
warning.js
popup.html
popup.js
popup.css
04

Mở Chrome Extensions

Truy cập:

chrome://extensions
05

Bật Developer Mode

Bật Developer mode ở góc trên bên phải.

06

Load unpacked

Nhấn Load unpacked.

Chọn đúng thư mục:

URLChecker → Extension

Không chọn thư mục Backend.

07

Hoàn tất
